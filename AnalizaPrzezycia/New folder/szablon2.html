Średni czas życia estymujemy jako pole pod krzywą funkcji przeżycia. Dla danych cenzurowanych stosujemy metodę z ogonem wykładniczym.

1a) Estymator oparty na Kaplanie-Meierze


def mean_survival_KM(dane):
    m = np.sum(dane < np.max(dane))
    t_max = np.max(dane)
    
    area, _ = quad(lambda t: Kaplan_Meier(dane, t), 0, t_max, limit=100)

    s_max = Kaplan_Meier(dane, t_max)
    theta = -t_max / np.log(s_max) if s_max > 0 else 1
    tail = s_max * theta
    
    return area + tail

def mean_survival_FH(dane):

    tail = s_max * theta
    
    return area + tail

Lista 7: Przedziały ufności dla średniego czasu życia

Zadanie 1: Funkcja do konstrukcji przedziałów ufności


def ri(dane, si):
    t = dane[0]
    return np.sum(t >= si)


def di(dane, si):
    t = dane[0]
    delta = dane[1]
    return np.sum((t == si) & (delta == 1))

def Kaplan_Meier(dane, t=0):
    wynik = 1
    m = np.unique(dane[0][(dane[1] == 1) & (dane[0] <= t)])
    for i in m:
        n = ri(dane, i)
        d = di(dane, i)
        wynik *= (1 - d / n)
    return wynik

def mean_survival_KM(si, dane, tau):
    area, _ = quad(lambda k: Kaplan_Meier(dane,k), si, tau, limit=100)
    s_max = Kaplan_Meier(dane, tau)
    tail = - s_max * tau / np.log(s_max)

    return area + tail


def przedzial_ufnosci_KM(dane, alpha=0.05, tau=0.5):
    t = dane[0]
    delta = dane[1]
    czasy = np.argsort(t)
    t = t[czasy]
    delta = delta[czasy]
    dane = np.array([t, delta])

    zdarzenia = t[delta == 1]
    zdarzenia = zdarzenia[zdarzenia <= tau]
    s_max = Kaplan_Meier(dane, tau)
    suma = 0.0

    for si in zdarzenia:
        if ri(dane, si) - di(dane, si) == 0:
            continue
        integral = mean_survival_KM(si, dane, tau)
        tail = - s_max * tau / np.log(s_max)
        suma += (integral + tail)**2 * di(dane, si) / (ri(dane, si) * (ri(dane, si) - di(dane, si)))

    se = np.sqrt(suma)
    z = stats.norm.ppf(1 - alpha / 2)
    mu_hat = mean_survival_KM(0, dane, tau)

    lower = mu_hat - z * se
    upper = mu_hat + z * se

    return lower, upper

gdzie ri to liczba osób w grupie ryzyka w czasie si, a di to liczba zdarzeń w czasie si.

Funkcje wagowe w statystykach testowych

Interpretacja różnic w wartościach p

Test Log-rank (Mantel-Cox), który równomiernie waży różnice w całym okresie obserwacji, wykazał statystycznie istotną różnicę w funkcjach przeżycia między grupami (p=0.018308< 0.05) co prowadzi do odrzucenia hipotezy zerowej (H0). Natomiast pozostałe testy (Gehan-Breslow, Tarone-Ware, Peto-Peto), które nadają większą wagę różnicom we wczesnym etapie obserwacji, nie pozwoliły na odrzucenie H0. Wniosek jest taki, że istnieją istotne dowody na to, że stopień zaawansowania choroby wpływa na przeżycie pacjentek, szczególnie w późniejszych etapach, a standardowy test Log-rank potwierdza tę różnicę.

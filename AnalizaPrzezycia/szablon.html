1. Rozkład Weibulla z trzema parametrami EW(α, β, γ)

Rozważmy zmienną losową X ∼ EW(α, β, γ), gdzie:

  • α > 0 – parametr kształtu,
  • β > 0 – parametr skali,
  • γ ∈ (0, 1) – zewnętrzny parametr kształtu

Funkcja gęstości:


    def dEW(x, alpha, beta, gamma):
        qweibull_cdf = 1 - np.exp(-(x / beta)**alpha)
        weibull_pdf = (alpha / beta) * (x / beta)**(alpha - 1) * np.exp(-(x / beta)**alpha)
        return gamma * weibull_pdf * weibull_cdf**(gamma - 1)

Dystrybuanta:


    def pEW(x, alpha, beta, gamma):
        return (1 - np.exp(-(x / beta)**alpha))**gamma

Funkcja kwantylowa:


    def qEW(p, alpha, beta, gamma):
        return beta * (-np.log(1 - p**(1/gamma)))**(1/alpha)

Funkcja hazardu:


    def hazard_EW(x, alpha, beta, gamma):
        f = dEW(x, alpha, beta, gamma)
        F = pEW(x, alpha, beta, gamma)

        # Unikanie dzielenia przez zero
        survival = 1 - F
        return np.where(survival > 1e-10, f / survival, np.inf)

1.2. Wizualizacja funkcji hazardu

Funkcja hazardu przedstawia chwilową intensywność zajścia zdarzenia (np. awarii, zgonu) w danym momencie czasu, przy założeniu że zdarzenie nie zaszło wcześniej. Na poniższym wykresie możemy zaobserwować, jak różne kombinacje parametrów α, β i γ wpływają na kształt funkcji hazardu. Rosnąca funkcja hazardu sugeruje, że ryzyko zdarzenia wzrasta z czasem (starzenie się), podczas gdy malejąca funkcja wskazuje na zmniejszające się ryzyko (efekt wczesnej selekcji). Funkcja stała odpowiada rozkładowi wykładniczemu, gdzie ryzyko jest niezależne od czasu.

2.1 Generowanie danych cenzurowanych

Cenzurowanie I-go typu

W cenzurowaniu typu I wszystkie obserwacje są monitorowane do z góry ustalonego czasu t₀. Obserwacje, które nie zakończyły się zdarzeniem przed tym czasem, są cenzurowane 


     def first_type_error(t0, n = 10, lambdaa = 1, alpha = 1):
       ext = [dexp(lambdaa, alpha) for _ in range(n)]
       for i in range(len(ext)):
           if ext[i] > t0:
               ext[i] = t0
       return ext






Cenzurowanie II-go typu

Cenzurowanie typu II kończy badanie po uzyskaniu z góry ustalonej liczby m zdarzeń.


     def second_type_error(m, n = 10, lambdaa = 1, alpha = 1):
       ext = [dexp(lambdaa, alpha) for _ in range(n)]
       ext.sort()
       ext = ext[:m]
       ext += [max(ext) for _ in range(n - m)]
       return ext

Cenzurowanie losowe niezależne

W cenzurowaniu losowym każdy pacjent ma własny, losowy czas cenzurowania, który jest niezależny od czasu do zdarzenia. 


    def random_type_error(eta, n = 10, lambdaa = 1, alpha = 1):
       ext = [dexp(lambdaa, alpha) for _ in range(n)]
       ext2 = [np.random.exponential(scale=eta) for _ in range(n)]
       ext3 = []
       for i in range(len(ext)):
           if ext[i] > ext2[i]:
               ext3.append((ext[i], 1))
           else:
               ext3.append((ext2[i], 0))
       return ext3

4. Test ilorazu wiarygodności

4.1 Funkcja poziomu krytycznego


def exp_likelihood_ratio_test(data, theta0):
    #n = len(data)
    r = np.sum(data < np.max(data))
    data = np.sort(data)
    data_uncenzored = data[:r]
    s = np.sum(data_uncenzored)
    #t0 = data_uncenzored[-1]
    theta_hat = r / s

    def log_likelihood(theta, r, s):
        if theta <= 0:
            return -np.inf
        return r * np.log(theta) - theta * s


    log_L_mle = log_likelihood(theta_hat, r, s)
    log_L_h0 = log_likelihood(theta0, r, s)

    statistic = -2 * (log_L_h0 - log_L_mle)
    p_value = 1 - stats.chi2.cdf(statistic, df=1)

    return p_value
